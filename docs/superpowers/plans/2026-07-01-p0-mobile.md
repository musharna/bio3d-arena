# P0 Mobile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the arena usable and votable on a phone — responsive hamburger nav, an A/B viewer toggle, and a sticky vote bar — without touching the desktop layout.

**Architecture:** Pure frontend. A CSS checkbox-hack hamburger (works without JS) collapses the nav; a small JS segmented toggle switches which model shows on mobile; CSS sticky pins the vote bar. All mobile rules go inside the codebase's existing `@media (max-width: 720px)` block. Desktop (>720px) is byte-for-byte unchanged.

**Tech Stack:** Jinja2 templates, vanilla CSS + JS. Files: `app/templates/base.html`, `app/templates/arena.html`, `app/static/style.css`, `app/static/arena.js`. No new deps, no server-side changes.

## Global Constraints

- **Desktop unchanged above 720px** — every new rule lives inside `@media (max-width: 720px)` (extend the EXISTING block at `app/static/style.css:583`, do not add a second one) or is `display:none` by default and only shown on mobile. A 1440px screenshot must match the pre-change desktop.
- **Nav must work with JS disabled** — CSS-only checkbox hack (no JS for the nav).
- **No-JS safety for the A/B toggle** — the "hide inactive model-col" CSS rule is gated on a `body.js-ab` class that `arena.js` adds; with JS off, both models stay visible (stacked). Never hide a model unless JS is running.
- **Breakpoint = 720px** (the codebase's existing mobile breakpoint; `.pair`→1-col and `.vote-bar`→2-col already live there).
- Tap targets on the collapsed nav ≥ ~44px tall.
- Verify with the existing pytest suite (markup smoke) + a Playwright check at 390px and 1440px.

```js
// Mobile A/B toggle: mark JS active (gates the "hide inactive model" CSS) + wire the switch.
document.body.classList.add("js-ab");

function setAB(which) {
  document.querySelectorAll(".ab-btn").forEach((b) => {
    const on = b.dataset.ab === which;
    b.classList.toggle("is-active", on);
    b.setAttribute("aria-selected", on ? "true" : "false");
  });
  const cols = document.querySelectorAll(".pair .model-col");
  if (cols[0]) cols[0].classList.toggle("is-active", which === "a");
  if (cols[1]) cols[1].classList.toggle("is-active", which === "b");
}

document
  .querySelectorAll(".ab-btn")
  .forEach((b) => b.addEventListener("click", () => setAB(b.dataset.ab)));
```

Then in the `render(data)` function, after the two `el("fmt-b")…mount(…)` lines and before `setStatus("");` (line ~88), add:

### Task 3: Playwright visual verification (mobile + desktop regression)

**Files:**

- Create: `scripts/verify_mobile_ux.py` (a throwaway-style verification script; kept for re-runs)

**Interfaces:**

- Consumes: a running instance (booted separately). Produces pass/fail assertions + screenshots at 390px and 1440px.

- [ ] **Step 1: Write the verification script**

```python
# scripts/verify_mobile_ux.py
"""Visual verification for the P0 mobile changes. Boot the app on :8099 first, then run.
Asserts (390px): nav collapsed to burger; A/B toggle switches the visible viewer; vote bar sticky.
Asserts (1440px): burger + toggle hidden (desktop unchanged)."""
import sys
from playwright.sync_api import sync_playwright

BASE = "http://127.0.0.1:8099"
pw = sync_playwright().start()
b = pw.chromium.launch(args=["--no-sandbox"])
fails = []

# --- mobile ---
m = b.new_page(viewport={"width": 390, "height": 844})
m.goto(BASE + "/", wait_until="networkidle", timeout=15000)
m.wait_for_timeout(1500)
if not m.is_visible(".nav-burger"):
    fails.append("nav-burger not visible at 390px")
if m.is_visible("header.topbar nav a[href='/leaderboard']"):
    fails.append("nav links visible before toggle (should be collapsed)")
m.click(".nav-burger")
if not m.is_visible("header.topbar nav a[href='/leaderboard']"):
    fails.append("nav did not expand after burger click")
# A/B toggle: after a pair loads, clicking Model B shows slot-b, hides slot-a
if m.is_visible(".ab-toggle"):
    m.click(".ab-btn[data-ab='b']")
    m.wait_for_timeout(300)
    a_vis = m.is_visible(".pair .model-col:nth-child(1) .viewer-slot")
    b_vis = m.is_visible(".pair .model-col:nth-child(2) .viewer-slot")
    if a_vis or not b_vis:
        fails.append(f"A/B toggle wrong: A_visible={a_vis} B_visible={b_vis}")
else:
    fails.append(".ab-toggle not visible at 390px")

# --- desktop regression ---
d = b.new_page(viewport={"width": 1440, "height": 1000})
d.goto(BASE + "/", wait_until="networkidle", timeout=15000)
if d.is_visible(".nav-burger"):
    fails.append("nav-burger visible at 1440px (should be hidden)")
if d.is_visible(".ab-toggle"):
    fails.append(".ab-toggle visible at 1440px (should be hidden)")
b.close(); pw.stop()
print("FAILURES:", fails if fails else "NONE — all mobile+desktop checks pass")
sys.exit(1 if fails else 0)
```
